# Employee Manager

Laboratory project for the course "Professional Python".

## Description

Console application for managing employees and calculating payroll statistics.

## Requirements

Python 3.11+

## Installation

```
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

## Run

```
python -m employee_manager.main
```

## Project structure

- `src/employee_manager/models.py` — Employee data model
- `src/employee_manager/services.py` — business logic
- `src/employee_manager/main.py` — application entry point
